# PushPilot REST API

[Спецификация](openapi.yaml) &nbsp; • &nbsp; [Сайт](https://pushpilot.ru) &nbsp; • &nbsp; [SDK](https://github.com/pushplatform/sdks)

---

Этот репозиторий предназначен для OpenAPI-спецификации и документации клиентского REST API PushPilot.

Контракт описывает запросы, ответы, авторизацию, ограничения доступа и ошибки. Реализация API находится в закрытом серверном репозитории.

## Возможности API

| Операция | Назначение |
| :--- | :--- |
| Регистрация устройств и токенов | Подключение мобильных устройств и браузерных подписок |
| `POST /v1/messages` | Постановка сообщения в очередь отправки |
| `GET /v1/messages/{id}` | Статус сообщения и его отправок |
| `GET /v1/messages` | История сообщений |
| `GET /v1/deliveries` | История отправок по получателям |
| `GET /v1/analytics/deliveries` | Аналитика отправок |

Точные пути регистрации, параметры, схемы и доступные фильтры должны быть приведены в [OpenAPI-спецификации](openapi.yaml) по действующей реализации сервера.

## Авторизация и доступ

Клиентский API использует API-ключи с ограниченными правами доступа.

- `messages:send` — отправка сообщений.
- `messages:read` — чтение статусов, истории и аналитики.
- Доступ ограничен организацией, проектом и окружением согласно scope ключа.

Точный формат заголовка авторизации и права остальных операций указываются в спецификации. Серверные ключи отправки храните на своём backend.

## Статусы отправки

`sent` означает, что push-провайдер принял запрос. Это не является подтверждением получения уведомления устройством.

Поддерживаемые статусы, повторные попытки, TTL и правила идемпотентности описываются в контракте. Гарантия exactly-once для внешней отправки не заявляется.

## Состав репозитория

| Файл или каталог | Содержимое |
| :--- | :--- |
| `openapi.yaml` | Каноническая OpenAPI-спецификация клиентского API |
| `docs/` | Авторизация, окружения, ошибки, лимиты и интеграция |
| `examples/` | Примеры curl с безопасными placeholders |
| `CHANGELOG.md` | История изменений контракта |

## Версионирование

Версия спецификации указывается в `info.version`. Изменения контракта отражаются в `CHANGELOG.md`.

Версия документа и префикс API `/v1` отслеживаются отдельно. При несовместимом изменении требуется описать переход клиентов на новый контракт.

## Обратная связь

Об ошибках в документации и запросах на улучшение пишите в [Issues](https://github.com/pushplatform/pushpilot-api/issues).

Укажите версию контракта, операцию и ожидаемый результат. Не публикуйте API-ключи, credentials или токены устройств.

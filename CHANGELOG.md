# История изменений

## 1.0.0 — 2026-10-12

- Добавлен публичный OpenAPI 3.0.3 по зарегистрированным маршрутам сервера.
- Описаны регистрация устройств/подписок, привязка пользователя, отправка, статусы,
  история, аналитика и Web Browser API.
- Добавлены русский быстрый старт, curl и JSON-примеры с безопасными placeholders.
- Зафиксированы фактические ошибки, idempotency, сериализация истории, ограничения
  окружений, TTL и семантика `sent = provider accepted`.
